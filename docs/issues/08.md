## Critérios de aceite

- [ ] docker compose up --build inicia frontend 5173 e backend 8000.
- [ ] Swagger disponível em /docs.

- [ ] Segredo fornecido pelo ambiente, nunca incorporado à imagem.
- [ ] Builds usam lockfiles; arquivos locais e segredos excluídos do contexto.
