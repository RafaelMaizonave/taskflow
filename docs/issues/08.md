# Entregar Docker Compose e persistência

Criar Dockerfiles e docker-compose.yml para execução reproduzível.

## Dependências

05, 07

## Critérios de aceite

- [x] docker compose up --build inicia frontend 5173 e backend 8000.
- [x] Swagger disponível em /docs.
- [x] SQLite persiste por volume após recriação dos contêineres.
- [x] Segredo fornecido pelo ambiente, nunca incorporado à imagem.
- [x] Builds usam lockfiles; arquivos locais e segredos excluídos do contexto.

## Evidências locais

`python3 scripts/validate_compose.py`: build e inicialização dos serviços, Swagger, proxy e persistência de usuário e tarefa após recriar o backend aprovados. O teste usa projeto e volume exclusivos e portas disponíveis, preservando o ambiente de desenvolvimento. As portas padrão continuam 5173 e 8000.
