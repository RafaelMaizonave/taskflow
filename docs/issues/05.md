# Cobrir autenticação e tarefas com testes de integração

Usar Pytest e HTTPX com banco SQLite isolado por teste e habilitar a suíte no CI.

## Dependências

04

## Critérios de aceite

- [ ] Cadastro, duplicidade, login válido/inválido e ausência de autenticação.
- [ ] Token expirado, inválido e usuário inexistente.
- [ ] CRUD, filtros, pesquisa e validação de campos.
- [ ] Isolamento entre dois usuários em leitura, alteração e exclusão.
- [ ] Banco de desenvolvimento nunca utilizado; pytest executa testes e passa no CI.
