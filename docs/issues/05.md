# Cobrir autenticação e tarefas com testes de integração

Usar Pytest e HTTPX com banco SQLite isolado por teste e habilitar a suíte no CI.

## Dependências

04

## Critérios de aceite

- [x] Cadastro, duplicidade, login válido/inválido e ausência de autenticação.
- [x] Token expirado, inválido e usuário inexistente.
- [x] CRUD, filtros, pesquisa e validação de campos.
- [x] Isolamento entre dois usuários em leitura, alteração e exclusão.
- [ ] Banco de desenvolvimento nunca utilizado; pytest executa testes e passa no CI.

## Evidências locais

`docker compose run --build --rm backend-quality uv run pytest -q`: 106 testes aprovados com SQLite temporário por teste, incluindo autenticação, CRUD e isolamento. A execução do CI remoto após a publicação continua pendente.
