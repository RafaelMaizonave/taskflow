## Critérios de aceite

- [x] Cadastro retorna 201; e-mail duplicado retorna 409.
- [x] Senha armazenada com Argon2; e-mail normalizado.
- [x] Login retorna JWT com expiração; credenciais inválidas retornam 401.
- [x] GET /api/v1/auth/me exige Bearer válido.
- [x] Erros consistentes e nenhuma exposição de senha/hash.
