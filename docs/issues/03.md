## Critérios de aceite

- [ ] Cadastro retorna 201; e-mail duplicado retorna 409.

- [ ] Login retorna JWT com expiração; credenciais inválidas retornam 401.
- [ ] GET /api/v1/auth/me exige Bearer válido.
- [ ] Erros consistentes e nenhuma exposição de senha/hash.
