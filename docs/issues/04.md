# Implementar CRUD de tarefas com isolamento por usuário

Criar endpoints de tarefas, pesquisa por título e filtro de status.

## Dependências

03

## Critérios de aceite

- [ ] POST/GET/PATCH/DELETE conforme contrato REST.
- [ ] Campos titulo, descricao, status, data_criacao e user_id.
- [ ] Status pending, in_progress e completed.
- [ ] Consultas e mutações limitadas ao usuário autenticado; acesso cruzado retorna 404.
- [ ] PATCH distingue omissão de null; DELETE retorna 204.
