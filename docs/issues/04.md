# Implementar CRUD de tarefas com isolamento por usuário

Criar endpoints de tarefas, pesquisa por título e filtro de status.

## Dependências

03

## Critérios de aceite

- [x] POST/GET/PATCH/DELETE conforme contrato REST.
- [x] Campos titulo, descricao, status, data_criacao e user_id.
- [x] Status pending, in_progress e completed.
- [x] Consultas e mutações limitadas ao usuário autenticado; acesso cruzado retorna 404.
- [x] PATCH distingue omissão de null; DELETE retorna 204.

## Situação da implementação

Implementada em worktree separado, integrada ao backend e validada localmente com testes unitários, integração e E2E HTTP real. Implementação entregue no commit correspondente à issue. Consulte docs/BACKEND.md para contratos e decisões.
